# 电磁场与电磁波 · 虚拟实验室

基于深圳技术大学 SG00217 教学大纲制作。平台按大纲的十个理论章节组织 44 个交互案例，每个案例提供 Three.js 三维场景和 HTML5 Canvas 实时曲线。课程目录含课内实践入口，收录实践项目表中的波导分析与项目详述中的偶极子天线。

## 发布到 GitHub Pages

1. 将 `em-lab` 作为 GitHub 仓库的根目录提交到默认分支，确保 `dist/index.html` 和 `.github/workflows/pages.yml` 位于对应路径。
2. 打开仓库的 **Settings → Pages**，在 **Build and deployment → Source** 中选择 **GitHub Actions**。工作流已经在项目中配置好。 [GitHub 官方配置说明](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
3. 首次启用后，在 **Actions → Deploy to GitHub Pages → Run workflow** 中选择默认分支运行。后续推送到默认分支时会自动部署。
4. 部署成功后，从 **Settings → Pages** 打开站点。项目站点的默认地址格式是 `https://<用户名>.github.io/<仓库名>/`。在地址末尾添加 `#rectangular-waveguide` 可直接打开矩形波导实验。

工作流直接发布 `dist/` 中的静态文件，无需安装依赖或运行构建命令。网页资源使用相对路径，仓库名称无需写入网页配置。

## 在本地运行

安装 Node.js 后，在本目录执行：

```powershell
node serve.mjs
```

在浏览器访问 http://127.0.0.1:4173/ 。若端口已被占用，可执行 `node serve.mjs 4174`。也可将 `dist` 下的文件放在普通静态 HTTP 服务器上。Three.js 与 OrbitControls 已随项目附带，本地运行无需访问外部 CDN。

## 使用方法

- 通过「教学章节」和「实验案例」两个下拉菜单选择内容。点击「课程目录」可查看各章与课内实践的对应案例。地址栏中的锚点可用于回到指定案例。
- 在三维视图中拖动旋转、滚动缩放、右键拖动平移。使用视图按钮切换正视或俯视，点击场量图例可切换对应图层。
- 调节参数时会重新计算场景、曲线和指标。时间工具栏支持播放、暂停、单步、回到起点、拖动时间轴与倍速播放。时间轴用于教学演示，场景内的快速振荡按可观察的速率展示。
- 三维交互需要支持 WebGL 2 的浏览器。Canvas 曲线与参数面板可在 WebGL 2 不可用时继续工作。

各案例根据其导读使用解析模型、近似模型或简化数值求解。三维场量可能按比例缩放，图表与指标标注了所用单位或归一化量。大纲要求的 COMSOL 通用有限元建模与后处理需要在相应软件中开展。
